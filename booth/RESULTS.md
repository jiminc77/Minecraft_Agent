- 초기 실패와 수정 기록을 `results/goals-iteration*.json`, `goals-core-iteration*.json`, `goals-core-before-physics-fix.json`에 보존했다. 나무 접근 위치, 후속 답변, 블록 1개/나무 한 그루 구분, 모델의 물리 지형 추측, 의미 검토의 API 오해를 수정했다.
- 이동 중간 검사에서는 요청 3칸에 3.9칸 이동, 2칸 이동 후 회전에서 최종 3칸으로 변한 사례와 중지 후 추가 이동 기준 초과가 있었다. physicsTick 안의 거리 검사와 반환 직전 위치 재검증을 추가했다. 한 번의 최종 통과를 모든 부하 상황에서의 거리·정지 보장으로 보지 않는다.

## 범위와 남은 한계

순차 계획은 기본 행동 최대 6단계다. 나무는 같은 종류의 면으로 연결된 원목 최대 32개를 고정하며 높은 나무에 닿기 위한 건축, 대각선 연결 가지, 서로 붙은 여러 나무의 의미적 구분은 지원하지 않는다. 계단은 가까운 정면의 단순 흙 벽, 한 칸 폭, 최대 네 칸 높이로 제한한다. 다른 블록이나 빈 발판이 있으면 실행하지 않는다. 실제 시험은 세 칸 높이이며 가능한 모든 지형/높이 조합을 실험한 것은 아니다.

지형 검사·범위 제한은 시스템 제어이며 한국어 문장별 분기는 없다. 모델은 Qwen 30B 그대로고, 공개 Mindcraft/Mineflayer 동작과 길찾기를 재사용했다. 재시도는 내부 계획 수정 한 번뿐이다. 자유로운 장기 계획, 자율 건축, 재료 조달, 운영판 전환, 정식 systemd 유닛, 물리 ESC와 영상 지연 측정은 하지 않았다.

- 수행해야 하는 단일 요청 433개: 정확한 행동 선택 **381**, 수행 대신 **확인 질문 50 / 수행 불가 1**, 잘못된 행동 선택 **1**.

- 버튼·수동 개입 등 시스템 이벤트 **18**: 언어 검사에서는 실행하지 않았다. 아래 실제 게임 검사에서 별도로 검증했다.
