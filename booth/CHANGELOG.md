# 2026-10-02 추가: 자연스러운 이동 범위 확대

- 사용자 선택에 따라 자연스러운 행동 범위를 우선 확장. 연속 걷기, 최대 100칸 이동, 점프와 이동의 동시 수행, 방향 기준 육지 찾기를 추가했다. 발화별 행동 분기를 추가하지 않고 구조화된 travel/land 목표를 모델이 선택하고 독립 의미 검토를 거친다.
- 연속 걷기는 새 입력·중지·수동 개입 또는 75초 제한으로 중단. 유한 이동은 실제 거리/방향을 다시 검사한다. 점프 이동은 도착 전 3칸부터 새 점프를 멈추고 착지 후 걷기로 마무리한다.
- 육지는 요청 방향 24칸 내 마른 발판/머리 공간과 시야를 검사하고 공개 Mineflayer Pathfinder로 이동. 물을 불투명 장애물로 취급하지 않으며 지지 블록 상단으로 시야를 검사한다. 접근 도중 채굴/설치하지 않는다.
- 실제 100칸 시험에서 MindServer의 15초 booth-control 중계 제한을 발견했다. 격리 사본의 execute 응답 제한을 85초로 맞추고 stop/reset은 기존 15초를 유지했다. installer가 해당 파일도 백업하고 변경한다.
- 첫 시험의 100칸 통신 실패, 점프 이동 11칸 초과, 육지 미발견을 results/natural-live-before-fix.json에 보존. 중간 결과는 natural-live-after-bridge.json. 반복 점프는 키 겹침과 관측 위치의 상승 구간으로 검사한다. 기존 onGround 기반 점프 카운터는 연속 바운스 횟수를 누락할 수 있어 횟수 정답으로 쓰지 않는다.
- 변경 전 backups/pre-natural-* 보존. 8765/8767은 그대로 유지. 기존 500개 결과는 이번 확장 버전의 전수 검증으로 간주하지 않는다.
